# Qiskit-FallFest

Welcome to my **Qiskit Fall Fest** repository! 🎉

This repository contains hands-on Jupyter notebooks exploring the fundamentals of quantum computing using **Qiskit**, IBM's open-source quantum computing software development kit. Through practical experiments and quantum circuit implementations, this project explores essential quantum concepts, algorithms, and quantum communication protocols.

The goal is to build a strong foundation in quantum computing through interactive coding and experimentation.

## 📚 Projects Included

### 1. Getting Started with Qiskit
**Notebook:** `get_started_with_qiskit.ipynb`

An introduction to Qiskit and the basics of building and executing quantum circuits.

**Topics covered:**
- Introduction to quantum computing and Qiskit
- Creating quantum circuits
- Applying quantum gates
- Measuring qubits
- Running circuits using quantum simulators

### 2. Quantum Superposition
**Notebook:** `superposition_with_qiskit_fallfest.ipynb`

Explores one of the fundamental principles of quantum mechanics: superposition.

**Topics covered:**
- Understanding qubits and superposition
- Applying the Hadamard gate
- Creating quantum states
- Measuring qubits and analyzing measurement outcomes

### 3. Bell's Inequality
**Notebook:** `bells_inequality_with_qiskit_fallfest.ipynb`

Explores quantum entanglement and the violation of Bell's inequality, demonstrating how quantum correlations differ from the predictions of local hidden-variable theories.

**Topics covered:**
- Introduction to quantum entanglement
- Creating entangled quantum states
- Understanding Bell's inequality
- Measuring quantum correlations using Qiskit

### 4. Quantum Teleportation
**Notebook:** `quantum_teleportation_fallfest.ipynb`

Demonstrates the quantum teleportation protocol, which transfers an unknown quantum state using shared entanglement and classical communication.

**Topics covered:**
- Quantum entanglement and Bell states
- Quantum teleportation protocol
- Quantum gates and measurements
- Classical communication and correction operations

### 5. Grover's Search Algorithm
**Notebook:** `grovers_fallfest.ipynb`

Explores Grover's algorithm, a quantum search algorithm that can provide a quadratic speedup over classical unstructured search.

**Topics covered:**
- Introduction to quantum search
- Oracle construction
- Amplitude amplification
- Grover diffusion operator
- Measuring and analyzing search results

## 🚀 Getting Started

### Option 1: Run on Google Colab

The notebooks can be opened and executed in Google Colab, allowing you to experiment without setting up a local Python environment.

1. Open any notebook in this repository.
2. Select the option to open it in Google Colab, if available.
3. Install any dependencies specified in the notebook.
4. Run the cells sequentially and explore the results.

### Option 2: Run Locally

**Step 1: Clone the repository**

```bash
git clone https://github.com/Mounica2045/Qiskit-FallFest.git
cd Qiskit-FallFest
```

**Step 2: Create a virtual environment (recommended)**

```bash
python -m venv .venv
```

Activate it:

Windows:
```bash
.venv\Scripts\activate
```

macOS/Linux:
```bash
source .venv/bin/activate
```

**Step 3: Install the dependencies**

```bash
python -m pip install qiskit jupyter
```

Install any additional packages required by the individual notebooks.

**Step 4: Launch Jupyter Notebook**

```bash
jupyter notebook
```

Open the notebook you want to explore and run its cells.
